# Cindy for fnOS

在飞牛 NAS 上运行 [Cindy](https://github.com/makecindy/cindy)：打开飞牛桌面上的图标，看到的就是 Cindy 桌面版的原版界面，AI Agent 在你自己的 NAS 上 7×24 小时待命。

> **开发中**：项目还处于早期阶段，尚未发布可安装的版本。进度见 [TODO.md](TODO.md)。

## 能带来什么

- **原版界面，不是简化版。** 界面直接来自 Cindy 官方源码，和桌面版一致。
- **一直在线的 Agent。** 任务在 NAS 上运行，关掉浏览器、合上电脑都不会中断。
- **用飞牛的方式操作文件。** 用飞牛的目录选择器给 Agent 授权工作目录；Agent 生成的文件可以一键在飞牛文件管理器中打开；在文件上右键即可「交给 Cindy」。
- **不需要额外的电脑或虚拟机。** 从飞牛应用中心安装，像其他飞牛应用一样启动、停止和升级。

## 功能可用性

飞牛版的后台是 Cindy 官方的无界面 Host。Cindy 正在把桌面版的后台能力逐步迁移到 Host，因此部分功能暂时不可用，会随上游更新陆续开放。

| 功能 | 状态 |
|---|---|
| 任务、对话、流式回复、停止、历史记录 | 计划中（P1） |
| 工具执行与权限确认 | 计划中（P1） |
| Cindy 账号登录、自定义模型供应商（API Key） | 计划中（P1） |
| 飞牛目录选择器、在飞牛中打开文件、跟随飞牛主题 | 计划中（P2） |
| 右键文件「交给 Cindy」 | 计划中（P2） |
| 内置 Agent：Pi | 计划中（P1） |
| 内置 Agent：Claude Code、Codex | 不内置 |
| 插件、定时任务、伙伴与多 Agent | 等待上游 Host 支持 |
| 截图、桌面控制等需要图形桌面的功能 | 不支持（NAS 没有图形桌面） |

状态会根据实测结果更新。

## 系统要求

- 飞牛 fnOS 1.2.0401 或更高版本（x86 或 ARM）
- 一个 Cindy 账号

## 安装

发布后从 [Releases](../../releases) 下载对应架构的 `.fpk`，在飞牛应用中心选择「手动安装」。

## 安全须知

Cindy 是能读写文件、执行命令的 Agent。飞牛版的安全设计如下：

- 只有飞牛管理员能打开 Cindy。
- Agent 以独立的应用用户运行，只能访问默认工作区和你授权的目录。
- 账号凭据加密保存在应用数据目录中。密钥由应用自行管理，以便 NAS 重启后自动恢复；能拿到 NAS root 权限或硬盘的人可以解密这些凭据。
